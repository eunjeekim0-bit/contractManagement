모크업 공유 README

파일 구성:
- templates/mockups/* : mockup HTML 파일들
- static/css/mockup.css : mockup 전용 스타일

로컬에서 미리보기 방법:
1) 파일 직접 열기 (간단): `open templates/mockups/index_mockup.html`
2) 간단 HTTP 서버로 열기 (권장):
```
cd "$(dirname "$0")"
python3 -m http.server 8000
# 브라우저에서: http://localhost:8000/templates/mockups/index_mockup.html
```

공유 방법 제안:
- ZIP 파일로 압축하여 이메일/메신저로 전송.
- GitHub 저장소에 업로드하고 GitHub Pages로 공개.
- 구글 드라이브/원드라이브/Dropbox에 업로드 후 링크 공유.

원하시면 제가 ZIP으로 묶거나, GitHub에 올려드리겠습니다. 권한이 필요합니다.
